# Front Door video brand kit

Values mirror `frontend/src/index.css`: warm paper, ink, Valio teal, and the lime primary action. Typography uses the
system UI face used by the product so the video reads like the native chef interface.

The video uses teal for product identity and lime only for the door/light and positive action moments. The kit has no
logo asset; the composition uses the product name as type rather than redrawing a logo.
